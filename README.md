**Leonida Legend** — an offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. All 55 official trophies are here with their official names, descriptions and grades, and every trophy carries a guide written in our own words that cites its sources (the official list as published by Exophase and PSNProfiles). A five-stage roadmap to the platinum — story in order, missable watch-outs, collectibles and counts, activities and clean-up, the platinum itself — is built from the official descriptions, and the four trophies those descriptions tie to one-time moments are flagged as missable, with the reasoning shown. Progress, counters for the 20 counted trophies and the spoiler shield (which hides story trophies until they are earned) are saved in the browser's localStorage and can be exported to a file and imported back. The app is plain static files: it works with the network off and loads nothing beyond its own files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. To build the hand-in dossier instead, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
